# Infrastructure locale

Ce dossier décrira Docker Compose, PostgreSQL, RabbitMQ, reverse proxy TLS, certificats locaux, réseaux et profils.

Les services vulnérables écoutent uniquement sur l'hôte local par défaut. Les ressources portent un préfixe propre au laboratoire ; arrêt et reset ne ciblent rien d'extérieur. Clés, tokens et certificats sont factices et régénérables.
