# Rapports

`remediation.md` accueillera le mini-audit actionnable : périmètre, méthode, synthèse, constats, preuves expurgées, causes, impacts, priorités, recommandations, tests, risques résiduels et limites.

Le rapport est formatif et non noté. Il doit permettre à une équipe de développement de reproduire puis vérifier le problème sans exposer de donnée inutile.
