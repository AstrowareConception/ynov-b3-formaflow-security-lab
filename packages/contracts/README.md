# Contrats

Ce dossier contiendra les contrats OpenAPI et événements nécessaires aux parcours de sécurité et RGPD.

Les variantes vulnérables ne modifient pas silencieusement le contrat public. Erreurs, authentification, données personnelles et versions restent documentées afin que les tests puissent distinguer comportement fonctionnel et contrôle de sécurité.
