# Preuves

`recognition/`, `remediation/` et `audit/` séparent les trois étapes. Chaque preuve précise tag, profil, état initial, action minimale, résultat, cause, correction ou hypothèse, reset et limite.

Les tokens sont tronqués, les données sont synthétiques et les captures ne révèlent rien d'extérieur au laboratoire. Une preuve ne doit jamais conserver un payload destructif ou une information d'accès réutilisable.
