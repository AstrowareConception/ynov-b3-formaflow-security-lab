# Preuves CDAN `security-rgpd`

Les preuves sont réparties entre `recognition/`, `remediation/` et `audit/`. `templates/evidence-record.md` est le gabarit ; les fichiers `provided-*.md` sont des exemples fournis, jamais une production individuelle. Les jetons, secrets, cookies complets et données inutiles sont exclus.

Chaque preuve relie identifiant, contexte, commit/tag, environnement, état initial, commande minimale, attendu, observé, interprétation, cause ou hypothèse, provenance, contributeur, confidentialité, vérification, résultat de vérification, limites, risque résiduel et reset.
