# Données personnelles représentées

Toutes les valeurs sont synthétiques. Le laboratoire représente email, nom d’affichage, bio, préférence newsletter, commande, paiement simulé, inscription, notification, session, export, demande d’effacement, consentement versionné et trace d’audit.

Les mots de passe de démonstration ne sont jamais réutilisables ailleurs. Les jetons sont éphémères et expurgés des preuves. Les événements n’embarquent ni email ni profil. Les journaux structurés doivent conserver un identifiant de corrélation, un type d’action et un résultat, sans credential.

Menaces principales : accès horizontal, injection, interprétation de contenu, usurpation, collecte excessive, propagation incomplète de l’effacement et conservation injustifiée.
