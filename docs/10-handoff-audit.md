# Handoff vers Rétro-ingénierie & Audit de code

## Principe

Le prochain module change volontairement de système. AtlasLegacy est une codebase inconnue et polyglotte. SecureLab ne transmet donc ni son code ni une liste de failles à retrouver.

## Contenu de `handoff/audit-method-reference/`

- méthode de cadrage d'un audit court ;
- vocabulaire observation/hypothèse/constat/faux positif/limite ;
- gabarit de preuve minimale expurgée ;
- gabarit de constat et de rapport ;
- exemple neutralisé de cause racine ;
- exemple de priorisation et risque résiduel ;
- checklist de retest ;
- exemples RGPD anonymisés ;
- règles éthiques et de confidentialité.

Le paquet est publié dans `reference-final`. AtlasLegacy repart séparément au tag `audit-start`, sans dépendance technique avec FormaFlow.
